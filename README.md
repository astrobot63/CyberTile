# CyberTile

A calming, neon 3D arcade survival game built with Three.js and Vite. Jump over cities, earn credits, and unlock new ball colors.

## Run locally

```sh
npm install
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

The game includes an endless platform run, a moving cyberpunk city backdrop, and a shop with unlockable player colors. Shop credits and owned styles are saved in the browser.
